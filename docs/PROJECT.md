# PROJECT.md — CareerOps Agent

## 한 줄 정의

개인 취업 자동화 에이전트. 채용공고 수집·적합도 판단·알림·근거 기반
자기소개서 작성을 지원한다.

## 사용자

프로젝트 소유자 1인. 대기업/공기업/은행·금융권 IT/전산/AX 신입·인턴 채용을
목표로 지원 활동을 자동화·보조한다.

## 최종 제품 목표

1. 대기업, 공기업, 은행/금융권의 IT/전산/AX 신입·인턴 채용공고를 자동 수집한다.
2. 사용자의 학력, 자격증, 프로젝트, 경험, 지원 희망 분야를 기준으로 지원
   가능 여부와 적합도를 판단한다.
3. 신규 공고, 추천 공고, 마감 임박 공고를 매일 아침 카카오톡으로 전달한다.
4. 사용자가 보유한 이력서, 포트폴리오, 경험정리, 기존 자기소개서를
   Personal Knowledge Base(PKB)로 관리한다.
5. 자소서 문항이 들어오면 다음 단계를 거쳐 초안을 생성한다:
   문항 분석 → 평가 역량 추출 → 관련 경험 검색 → Evidence Sheet 생성 →
   자기소개서 초안 → Fact Check → Style Check.
6. AI가 사용자가 하지 않은 경험이나 수치를 생성하지 못하도록 근거 기반
   검증 구조를 갖춘다.
7. 모든 주요 Agent 작업의 품질과 효율을 처음부터 측정한다.

## 스코프 밖 (현재)

- 다인 사용자/멀티테넌시 지원
- 자동 지원서 제출(원서 자동 접수) — 우선은 알림/추천/초안 작성까지
- 채용공고 출처 사이트의 이용약관을 위반하는 수집 방식
